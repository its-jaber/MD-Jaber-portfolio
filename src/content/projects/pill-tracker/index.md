## Overview

Pill Tracker is a mobile app idea for keeping track of daily medicines. This prototype is the main "Today" screen.

## What the screen shows

- A greeting with the date and a notifications icon
- A "Pro trial" banner
- A daily progress card ("0 of 0 medicines taken today") with a link to history
- A medicine search field and an "All caught up!" empty state
- Bottom navigation (Today, Upcoming, Calendar, History) with a central add button

## Status

This is a UI prototype and its functionality is unverified. Reminders, saving medicines, history and the subscription trial are not confirmed to work.
